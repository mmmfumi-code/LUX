## 0. 企画会議ログ（Strategist × Designer）

**Strategist**（Step 2 テーマ提案）：金曜は Cute メインで、動物案を入れる回。候補は F1「ティッシュ、最後の数枚が取り出せない」（②形で伝える、カバの口）、F2「黒い服の日に限って、猫が膝に乗ってくる」（③動物と暮らす）、F3「ハロウィン飾り、賃貸だと壁に貼れない」（①ヤモリの足）。誰にでも起きることで、寒暖差で鼻をかむ回数が増える時期にも合う F1 を推します。F2 はペットを飼っていない人が止まらないので、次の動物回に回したい。問いは2つ。カバの口で「最後の数枚」を機構として解けるか。飾りの形ではなく、形そのものが使い方を伝えることが条件。A/B を動物違いではなく機構違いにできるか。

**Designer**（Step 3 回答）：原因は、残りが減ると束の上面が取り出し口から遠ざかり、次の1枚の端が引っ込んで落ちることです。取り出し口と束の上面の距離をゼロに保てば解決します。上から近づけるのが A のカバ「DIPPO」。重りの入ったカバの頭が落とし蓋になり、束と一緒に沈みます。原価 約¥780 / ¥2,980 で推奨です。下から押し上げるのが B のワニ「CROCLIFT」。定荷重ばね2本で底板を上げます。原価 約¥1,000 / ¥3,280 です。必然性は、カバが水に沈んで目と耳だけを出す動物であること。沈み具合と残量を説明なしで伝えられます。懸念は3つあります。落とし蓋式のティッシュケースは既製品にあるので、「カバで機構が新しい」とは言えない。新しいのは沈み具合＝残量が一瞬で読める点なので、コピーはそこに寄せてほしい。箱から束を出す手間は残るので、「ソフトパックがそのまま入る」を利点として出すこと。投票の問いは「沈むカバ派 / 押し上げるワニ派」にしてほしい。

**Strategist**：既製品との差分は、隠すより先に言うほうが強いと思っています。7枚目の A/B 比較表の上に「落とし蓋式のケースは、実はもうある。今回の工夫は、残りが『沈み具合』で読めること」と1行で書きます。企業の担当者から見ると、既存品を知ったうえで差分を出せる人に見える。コメントで「それ、もう売ってる」と指摘されても、先に答えてあることになります。残量の見せ場は5枚目の3コマ（満杯・半分・残り数枚）にします。

**Designer**：それでいいと思います。表に「既製の落とし蓋」の列を足すのはやめてください。特定商品との比較に見えるので。1行の文章にとどめてもらえれば十分です。

**Strategist**：列は足しません。次に投票の問いについて。「沈むカバ派 / 押し上げるワニ派」で合意します。「カバ派 / ワニ派」だけだと見た目の人気投票になり、企業向けの需要検証として使えない。機構の動詞を入れることで、理由のコメント（「最後まで取れそう」「残りがわかるのがいい」）も付きやすい。ストーリーズの投票スタンプも「沈むカバ / 押し上げるワニ」にします。

**Designer**：推奨は A ですが、投稿では A を勝たせる構成にしないでください。B が残量が見えない点は、側面に窓を付ければ解決できる、と表の注記に書けます。

**Strategist**：公平に見せます。A・B を同じ枚数（各1枚の主役カット）にして、比較表には B の強み（最後の1枚まで押し当て続ける機構）と窓の注記も書く。キャッチは懸念に合わせて残量に寄せたいので、DIPPO は「減るほど、沈む。残りは、カバが教えてくれる。」、CROCLIFT は「最後の1枚まで、背中から。」でどうですか。

**Designer**：どちらも原理と一致しているので問題ありません。「ソフトパックがそのまま入る」は、仕様の注記として比較表に入れてください。

**Strategist**：入れます。ストーリーズの2問目として「ティッシュは箱派？ソフトパック派？」の投票も取ります。ティッシュメーカーとのタイアップの材料になります。

**合意事項**
- 採用案：A「DIPPO」（沈む落とし蓋、推奨）vs B「CROCLIFT」（ばねで押し上げ）の機構違いの A/B
- 見せ場：5枚目の3コマ。カバが沈んで目と耳だけになる＝残りが少ない
- 既製品との差分：7枚目の比較表の上に1行で先に書く（「落とし蓋式はもうある。工夫は残量が沈み具合で読めること」）。既製品との比較の列は作らない
- 投票の問い：「沈むカバ派 / 押し上げるワニ派」を採用（機構の動詞を入れて、見た目の人気投票にしない）
- 削ったもの：A を勝たせる構成、B への窓の追加（注記で可能性だけ示す）、ワニの歯・水しぶき・光沢塗装

## 1. テーマ

寒暖差で鼻をかむ回数が増える10月、箱ティッシュの「最後の数枚が取り出せない」問題を、取り出し口と束の距離をゼロに保つ2つの機構で解決し、どちらがいいかをフォロワーに聞く。

## 2. ユーザー課題

- あるある（表紙コピー）：**「ティッシュ、最後の数枚が取り出せない」**
- 具体的な不便
  - 残りが少なくなると、箱の底まで手を突っ込む
  - つまんだ1枚が途中で切れる、次の1枚が落ちて出てこない
  - 片手で取れず、鼻をかみたいときに限って手間取る
- なぜ起きるか（原因）：残りが減ると束の上面が取り出し口から遠ざかり、次の1枚の端が引っ込んで落ちる
- 既存の対処と限界
  - 箱を振る、底を押す：その場しのぎ
  - 落とし蓋式のケース：すでにあるが、残量は蓋の高さでしか読めない

## 3. 解決方法

- 解決の原理（1文）：**取り出し口と束の上面の距離をゼロに保つ。上から近づけるか（A）、下から押し上げるか（B）。**
- 検討した案と比較

| 観点 | A：カバ「DIPPO」（推奨） | B：ワニ「CROCLIFT」 |
| --- | --- | --- |
| 機構 | **上から沈む**：重りの入ったカバの頭が落とし蓋になり、束の上に乗って一緒に下がる | **下から押し上げる**：定荷重ばね2本で底板が上がり、束を背中のスリットに押し当て続ける |
| 形が使い方を語る | 口のスリットからティッシュをくわえている。残りが減るほどカバが「池に沈んで」目と耳だけになる | 背中のギザギザのスリットが次の1枚をつまみ、戻り落ちを防ぐ。細長い胴がティッシュの比率に合う |
| テイスト | Cute / Useful | Unexpected / Cute |
| 残量表示 | ◎ 沈み具合でわかる | △ 外から見えない（側面に窓を付ければ可） |
| 部品点数 | 4（池の器、頭の上下シェル、鋼板の重り） | 7（本体、底板、ばね2、ガイド2、背中の蓋） |
| 最後の1枚 | ◎ 自重で最後まで密着。押す力は残量に関係なく一定（約1.8N） | ○ 最後まで押し当てるが、束が軽くなるほど押す力が強くなる（残り数枚で最大 約2.5N）。引き出しがやや重くなる |
| 満杯時の引き出し | ○ 押す力 約1.8N で一定 | ◎ 束の重さでばねの力が相殺され、軽い（約0.5N） |
| 原価 / 売価 | 約¥780 / ¥2,980（26%） | 約¥1,000 / ¥3,280（30%） |
| 判定 | **推奨** | 投票の対抗案 |

## 9. CTA

- メイン：**「沈むカバ派？ 押し上げるワニ派？ A か B と、理由を一言」**（2択＋理由のコメント誘導）
- サブ：「7枚目の比較表、保存して見比べてください」（保存誘導）
- ストーリーズ連動
  - 投票1：「沈むカバ / 押し上げるワニ」
  - 投票2：「ティッシュは 箱派 / ソフトパック派」（ソフトパック訴求の需要データ）
  - 翌週月曜のストーリーズで結果と、多かった理由を発表する

## 13. 8要素スコア（1〜5、3以下は改善してから確定）

## 16. テイスト・動物タグ

- テイスト：メイン **Cute** / サブ **Useful**
- 動物 × Product Design：**②形で伝える**（カバ）。対抗案のワニも②
- 動物である必然性：カバは水に沈んで目と耳だけを出す動物なので、「減るほど沈む落とし蓋」の動きと残量表示を、説明なしで伝えられる。ただの丸い蓋では「沈む＝残りが少ない」が読めない

## 17. 現実性チェック

- [x] 分割線・組立方法を説明できる：A は池・上シェル・下シェル・重りの4部品。重りを上下シェルの間に超音波溶着で封入。B は本体に底板とばね2本を組み、ガイド2を短辺内壁に差し込み、背中の蓋をスナップ留め（詰め替え時に外す）

- [x] 電源・可動部・放熱などの逃げがある（該当する場合）：電源なし。A の可動部は蓋の自重で下がるだけで、池の内壁とのすき間は片側3mm（斜めでも引っかからない）。B の可動部は底板で、ガイドの縦溝で傾きを防ぎ、ばねの帯はガイドで覆って指が触れない。ばねは有効ストローク 100mm 以上で、力が不安定な巻き始めの区間を使わない
