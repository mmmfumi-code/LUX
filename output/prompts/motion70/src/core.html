KINETIC TYPE PROMPT BOOK — 70 MOTIONS

AIに貼るだけ。
文字が動く70の台本

テロップ、サムネ動画、リール冒頭、YouTubeのタイトルコール。文字が動くだけで、動画の「見てもらえる確率」は大きく変わります。

この本は、その文字演出をClaude・ChatGPT・Gemini に貼るだけで作れるプロンプトにした70本です。1ページに1モーション。左のモニターが「そのプロンプトで実際にできる動き」、右がコピーして使うプロンプトです。

PREVIEW
HOW TO USE

使い方：3分で1本目が動く

どのページも「共通仕様」と「モーション指示」の2段構えです。コピーボタンを押すと、両方が1つにまとまった完成プロンプトがコピーされます。

  1. ページを選んで、プレビューの文字を自分の言葉に変える
    モニター下の入力欄に文字を入れると、プレビューもプロンプトも同時に書き換わります。
  2. 画面比率を選んで「プロンプトをコピー」
    16:9（YouTube）、9:16（リール・ショート・TikTok）、1:1（フィード）から選べます。
  3. AIに貼って送信する
    Claude ならアーティファクトとしてその場で再生されます。ChatGPT・Gemini では出てきたコードを motion.html として保存し、ブラウザで開きます。
  4. 画面録画して、動画編集ソフトに読み込む
    Mac は Cmd+Shift+5、Windows は Win+Alt+R（Xbox Game Bar）。CapCut・Premiere・DaVinci に読み込めば、そのままテロップ素材になります。

共通仕様（すべてのコピーに自動で入ります）


    
思いどおりに動かないときの「追い指示」

    

      
症状AIにそのまま送る一言

      
        
動きが安っぽい・機械的「イージングを cubic-bezier(.16,1,.3,1) に統一して、全体を1.3倍ゆっくりにして」

        
迫力が足りない「登場の瞬間だけ、ブラー12px→0とスケール1.4→1を同時にかけて、画面を0.2秒だけ揺らして」

        
文字が読めない「動きが止まってから最低1.2秒は静止させて。文字サイズを1.3倍に」

        
ループの継ぎ目が気になる「最初と最後の状態を完全に一致させて、継ぎ目のないループにして」

        
背景を透明にして重ねたい「背景をグリーン(#00FF00)一色にして。クロマキーで抜きたい」

        
動画ファイルで欲しい「CanvasとMediaRecorderで録画して、1ループ分をWebMで保存するボタンを付けて」

        
日本語が豆腐（□）になる「Google Fonts の読み込みを document.fonts.ready で待ってから再生して」

      
    

    
この本のプロンプトが「通る」理由

    
動きを「かっこよく」と書いてもAIは平均点の動きしか返しません。この本では、すべてのモーションを秒数・イージング・数値（拡大率、角度、ずらし幅）で指示しています。プレビューの動きはその数値どおりに組んだものなので、同じ値で指示すれば近い動きが返ってきます。返ってきた動きが違うときは、数値を1つずつ動かして寄せてください。
