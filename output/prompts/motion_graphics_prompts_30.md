# AIで作れるモーショングラフィック プロンプト集 30選

Claude / ChatGPT / Gemini などのチャットAIに貼るだけで、**ブラウザで再生できるモーショングラフィック（HTML/CSS/JavaScript 1ファイル）** が作れるプロンプト集です。
できたHTMLは画面録画（macOS: `Cmd+Shift+5` / Windows: `Win+Alt+R`）すれば、そのままリール・ショート・スライド素材になります。

---

## 使い方

1. 下の **【共通ルール】** をコピーする
2. 作りたい番号のプロンプトをその下に貼る
3. `【 】` の部分を自分の内容に書き換えて送信
4. 出てきたコードを `.html` で保存してブラウザで開く（Claude ならアーティファクトでその場で再生）

### 【共通ルール】（毎回先頭に貼る）

```
あなたはモーショングラフィックデザイナー兼フロントエンドエンジニアです。
以下の条件で、ブラウザで開くだけで再生されるアニメーションを作ってください。

- HTML / CSS / JavaScript を1ファイルにまとめる（外部ライブラリはCDNのみ可：GSAP、anime.js、Three.js など）
- 画面サイズ：【1080×1920（縦）／1920×1080（横）／1080×1080（正方形）】で中央固定、余白は黒
- 読み込み後に自動再生、最後まで行ったらループ（ループ不要なら最後で静止）
- イージングは機械的にせず、ease-out / back / elastic など「気持ちいい動き」を優先
- 日本語フォントは Google Fonts の Noto Sans JP（太字は900）を使う
- 画面右下に小さく「R」キーでリプレイできるようにする
- コードだけでなく、動きの意図を3行で説明する
```

## A. テキスト・タイポグラフィ（1〜8）

### 1. 1文字ずつ跳ねて出るタイトル
```
テキスト「【今日から変わる3つの習慣】」を1文字ずつ下から跳ね上がるように登場させてください。
各文字は0.04秒ずつ遅らせ、back イージングで少しオーバーシュート。
全文字が出たら0.5秒後に下線が左から右へ伸びる。背景は【#111】、文字は白、下線は【#FF5A36】。尺は約3秒。
```

### 2. キネティック・タイポグラフィ（言葉が畳みかける）
```
「【考える】→【書く】→【届ける】→【変わる】」の4語を、0.6秒ごとに画面いっぱいの巨大文字で切り替えてください。
切り替えは、拡大しながらブラーで消え、次の語が縮小しながら登場。語ごとに背景色を【黒→赤→白→黒】と反転させる。
最後の語だけ1.5秒止めて、小さくサブコピー「【毎日の積み重ねが人生をつくる】」をフェードイン。
```

### 3. タイプライター＋カーソル点滅
```
「【AIに仕事を奪われる人と、AIで仕事が増える人の違い】」をタイプライター風に1文字ずつ表示してください。
タイプ音の代わりに、打つたびに文字がわずかに上下に揺れる演出を入れる。カーソルは点滅、打ち終わったら1秒後に
重要語「【AIで仕事が増える】」だけが蛍光ペンで塗られるように黄色のマーカーが左から引かれる。
```

### 4. グリッチ文字
```
テキスト「【SYSTEM UPDATE】」をグリッチ演出で表示してください。
RGBずれ（赤・シアンの残像）、横方向のスライスずれ、ランダムな文字化け（記号に一瞬置き換わる）を
0.1〜0.3秒間隔で不規則に発生させ、3秒後に正しい文字で安定させる。背景は走査線入りの黒。
```

### 5. 文字が粒子になって崩れ、別の言葉に再集合
```
Canvasで「【BEFORE】」の文字を約2000個の粒子で描き、1.5秒後に風で吹き飛ぶように散らしてください。
散った粒子は1秒かけて渦を巻きながら集まり「【AFTER】」の形になる。粒子の色は【白→#00E5FF】にグラデーション変化。
マウスを近づけると粒子が逃げるインタラクションも付ける。
```

### 6. 数字カウントアップ
```
「【0】」から「【12,800】」まで2秒でカウントアップする大きな数字を中央に表示してください。
最初速く、最後ゆっくり（ease-out-expo）。桁が増えるたびに数字が軽くバウンド。
数字の上に小さく「【フォロワー数】」、カウント完了と同時に紙吹雪が少し舞う。
```

### 7. マスクで切り抜かれるテキストリビール
```
3行のコピー
「【もう、】」
「【迷わない。】」
「【AI活用ロードマップ】」
を、各行が見えない枠の下からスッと出てくるマスクリビールで表示してください（行ごとに0.2秒遅延）。
最後の行だけ太字＆グラデーション文字（【#7B61FF→#FF61D2】）。全体で2.5秒。
```

### 8. 縦書き和風タイトル
```
縦書きで「【一期一会】」を、筆で書くように上から順に墨がにじみ出る演出で表示してください。
背景は和紙テクスチャ（CSSノイズで表現）、最後に右下へ赤い落款（はんこ）がポンと押される。
フォントは Noto Serif JP、色は墨色【#1a1a1a】。尺は約4秒。
```

## B. ロゴ・ブランド（9〜13）

### 9. ロゴのラインドロー
```
以下のSVGロゴ（なければ「【LUX】」の文字をアウトライン化したSVGを自作）を、
線が描かれていくストロークアニメーション（stroke-dashoffset）で2秒かけて描画し、
描き終わったら内側が塗りつぶされ、最後に光沢が左から右へ1回走る。
【ここにSVGを貼る（任意）】
```

### 10. 図形が組み合わさってロゴになる
```
円・三角・四角の3つの図形が画面外から回転しながら飛んできて、中央で組み合わさり
1つのシンボルになるロゴアニメーションを作ってください。合体の瞬間に軽い衝撃波（円が広がって消える）。
その下にブランド名「【LUX】」とタグライン「【make it shine】」が順にフェードイン。カラーは【#0F172A / #F59E0B】。
```

### 11. ネオンサイン点灯
```
「【OPEN】」をネオン管風に表示してください。最初は消灯状態、パチパチと2〜3回不規則に点滅してから点灯。
発光は text-shadow を多重にして滲みを出す。点灯後もごくわずかにちらつき続ける。背景はレンガ壁風の暗いグラデーション。
```

### 12. リキッド（液体）ロゴリビール
```
画面下からインクのような液体が波打ちながら上がってきて、画面を満たした瞬間に
液体がロゴ「【LUX】」の形に引いていくリビール演出を作ってください。SVGフィルター（feTurbulence / feDisplacementMap）で揺らぎを表現。
液体の色は【#2563EB】。尺は4秒。
```

### 13. エンドカード（チャンネル登録・フォロー誘導）
```
動画の最後に使うエンドカードを作ってください。
左に丸いアイコン枠（【アイコン画像URL】、なければイニシャル）、右に「【フォローして続きを見る】」ボタン。
ボタンは0.5秒ごとに軽く脈打ち、マウスカーソルのアイコンが動いてきてクリックすると波紋が出て「フォロー中」に変わる。
```

## C. データ・インフォグラフィック（14〜19）

### 14. 棒グラフが伸びる比較
```
以下のデータで横棒グラフを作り、棒が0から順番に伸びるアニメーションにしてください。
【ChatGPT: 62, Gemini: 18, Claude: 12, その他: 8】（単位：%）
棒の先端に数値がカウントアップしながら付いていく。1位の棒だけ色を変えて最後に光らせる。タイトル「【生成AIの利用シェア】」。
```

### 15. 円グラフ（ドーナツ）が描かれる
```
ドーナツグラフで【時間の使い方：仕事40% / 睡眠30% / 自由時間20% / その他10%】を表示してください。
時計回りに1区画ずつ描かれ、描かれるたびに凡例が横から出る。最後に中央へ「【自由時間はたった20%】」を表示。
```

### 16. 折れ線グラフが右肩上がりに
```
【1月〜12月の売上：10,12,11,15,18,17,22,26,25,31,38,45】の折れ線グラフを、
線が左から右へ描かれていくアニメーションで表示してください。線の下はグラデーションで塗りつぶし、
線の先端に光る点が付いて進む。最後の点で「【+350%】」の吹き出しがポップ。
```

### 17. ビフォーアフター比較スライダー
```
画面を左右に分割し、左に「BEFORE：【作業時間 5時間】」、右に「AFTER：【作業時間 30分】」を表示。
中央の境界線が自動で左右に往復し、最後に右側へスライドしてAFTERが画面全体を占める。
AFTER側の数字は大きく、色は【#22C55E】。
```

### 18. タイムライン（年表）が流れる
```
横スクロールで進むタイムラインを作ってください。
【2022 ChatGPT公開 / 2023 画像生成ブーム / 2024 動画生成の登場 / 2025 AIエージェント元年 / 2026 【ここに自分の年】】
カメラが左から右へ移動し、各年の点に到達するとカードが下からポップアップ。最後の年だけ大きく強調。
```

### 19. アイコンで比率を見せる（ピクトグラム）
```
人型アイコンを10×10＝100個並べ、そのうち【23】個だけが順番に色付きになるアニメーションを作ってください。
色付きが終わると「【4人に1人がAIを毎日使っている】」の文字が表示。アイコンはSVGで自作、色付きは【#F97316】、他はグレー。
```

## D. UI・プロダクト紹介（20〜24）

### 20. スマホ画面のUIデモ
```
中央にスマホのモックアップ（CSSで角丸の端末枠）を置き、その中で
【タスク管理アプリ】の画面が「一覧 → タップ → 詳細画面へスライド遷移 → チェック完了でチェックマークが弾む」
と自動操作されるデモアニメーションを作ってください。タップ位置に指の丸い影を表示。
```

### 21. AIチャットのやり取り再現
```
チャットUIで、ユーザー「【ブログのタイトル案を3つ出して】」→ AIが「入力中…」の3点リーダーを表示 →
回答が1文字ずつストリーミング表示される流れを再現してください。吹き出しは下からスッと出る。
回答内容：【①〜②〜③〜（自分で用意）】。ダークモードUI。
```

### 22. 機能紹介の3カード
```
3枚のカード【①自動要約 ②翻訳 ③画像生成】が、トランプを配るように扇状に広がって登場し、
1枚ずつ前に出て拡大 → アイコンが動き → 説明文が出る → 元に戻る、を順番に繰り返してください。
カードはガラス風（backdrop-filter: blur）、背景は動くグラデーション。
```

### 23. 通知が次々に届く演出
```
スマホのロック画面風の背景に、通知バナーが上から次々に積み重なっていく演出を作ってください。
通知内容：【「新しいフォロワー」「記事が購入されました ¥500」「コメントが届きました」…を8件】。
後半は通知の間隔が速くなり、最後に画面が通知で埋まって「【これが仕組み化の力】」とテキスト。
```

### 24. ブラウザ上のマウス操作デモ
```
ブラウザウィンドウ風の枠を作り、その中でマウスカーソルが動いて
「検索窓をクリック → 【AI 副業】と入力 → 検索ボタン → 結果がずらっと表示」
という操作を自動再生してください。クリック時にカーソル周りに波紋、入力は1文字ずつ。
```

## E. 背景・ループ素材（25〜28）

### 25. ゆらめくグラデーションメッシュ背景
```
4色【#FF7EB3 / #7AFCFF / #FEFF9C / #B28DFF】の大きなぼかし円がゆっくり漂い、混ざり合うメッシュグラデーション背景を作ってください。
10秒で完全ループ（つなぎ目が分からないように）。上に半透明のノイズを重ねて質感を出す。文字は載せない。
```

### 26. 幾何学パターンの無限ループ
```
正方形のグリッドに並んだ図形（円⇄四角⇄十字）が、中心から波紋状に順番にモーフィングしていく
無限ループアニメーションを作ってください。色は【白×黒】の2色、BGM映えするように1ループ2秒の一定テンポで。
```

### 27. 3D回転する地球／オブジェクト
```
Three.jsで、点（パーティクル）で構成された地球を中央でゆっくり回転させてください。
地表のいくつかの都市【東京・NY・ロンドン・シンガポール】から光の弧が飛び交う。背景は星空。マウスドラッグで回転可。
```

### 28. Lo-fi 風の作業用ループ
```
窓の外に雨が降り、机の上のマグカップから湯気が立ちのぼる、Lo-fi風のイラストループをCSSとSVGだけで作ってください。
雨粒・湯気・時計の秒針だけが動く。全体はくすんだ【紫×オレンジ】の夕暮れトーン。右上に小さく「【study with me】」。
```

## F. SNS・ショート動画向け（29〜30）

### 29. リール冒頭のフック（最初の2秒）
```
縦型（1080×1920）で、ショート動画の冒頭2秒に使うフック演出を作ってください。
画面が一瞬フラッシュ → 「【9割の人が知らない】」が大きくズームイン → 下から「【ChatGPTの隠し機能】」がスライドイン →
画面全体が軽くカメラシェイク。文字には黒いフチ取り、背景は【赤×黒】の集中線。
```

### 30. ランキング発表（第3位→第1位）
```
縦型で「【おすすめAIツール】ランキング」を発表するアニメーションを作ってください。
第3位【ツールA】→ 第2位【ツールB】→ 第1位【ツールC】の順に、ドラムロール風に数字が回ってから決定。
1位のときだけ王冠が落ちてきて、紙吹雪と光線が背景から放射。各順位の表示は2秒。
```

## うまくいかない時の追加指示（コピペ用）

| 困りごと | 追加で送る一言 |
|---|---|
| 動きがカクカク・安っぽい | 「イージングをGSAPの power3.out / back.out(1.7) に変えて、全体を1.2倍ゆっくりにして」 |
| 地味 | 「登場時にスケール0.8→1、ブラー10px→0を同時にかけて、背景にゆっくり動く光を足して」 |
| 文字が読めない | 「各テキストの静止時間を最低1.2秒確保して、文字サイズを1.5倍にして」 |
| ループの継ぎ目が目立つ | 「最初と最後のフレームを完全一致させて、シームレスループにして」 |
| 動画ファイルにしたい | 「CanvasをMediaRecorderで録画して、再生終了時にWebMをダウンロードするボタンを付けて」 |
| 色を変えたい | 「配色を【ブランドカラー #xxxxxx】をメインに、補色をアクセントにして全体を作り直して」 |

### 補足
- 動画生成AI（Sora / Veo / Kling / Runway など）で使う場合は、冒頭の【共通ルール】を外し、各プロンプトの末尾に「モーショングラフィックス、フラットデザイン、滑らかなカメラワーク、4K」を付けると近い雰囲気で生成できます（日本語テキストは崩れやすいので、文字は後から編集ソフトで載せるのがおすすめ）。
- `【 】` 内の数値・事例はすべて**サンプル**です。実際に発信する際は自分のデータに差し替えてください。
