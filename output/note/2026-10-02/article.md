# 企業デザイナーが副業を始める前に確認した7項目｜就業規則・競業・住民税・20万円

「副業、やってみたいけど会社的に大丈夫？」。インハウスデザイナーが副業で一番怖いのは、税金よりも、本業のデザインとぶつかることでした。この記事では、メーカーの企業デザイナーの僕が副業を始める前に実際に確認した7項目を、上司への相談文面と「20万円ルール」の整理表つきで書きます。「バレない方法」ではなく、**堂々と続けるための確認リスト** です。

## 1. 就業規則の「副業」条項を読む

最初にやるのは、自社の就業規則を読むことです。副業の扱いは会社ごとにだいたい次の3つのどれかです。

| パターン | 意味 | やること |
|----------|------|----------|
| 禁止 | 原則不可 | 無理に始めない。制度変更の予定を人事に聞く |
| 許可制 | 申請して許可が必要 | 申請書の様式と、審査の基準を確認 |
| 届出制 | 事前に届け出れば可 | 届出の様式・タイミングを確認 |

参考になるのが、厚生労働省の **モデル就業規則（副業・兼業の条文）** です。勤務時間外の副業を原則として認めたうえで、次の4つに当たる場合は禁止・制限できる、という形になっています。

1. 労務提供上の支障がある（本業に支障が出る）
2. 企業秘密が漏洩する
3. 会社の名誉や信用を損なう
4. 競業により企業の利益を害する

自社の規則がこの形なら、**「この4つに当たらないこと」を自分で説明できれば、話はかなり進めやすくなります**。以下の項目2〜5は、この4つをデザイナー向けに具体化したものです。

## 2. 競業：本業と同じジャンルの案件は受けない

デザイナーの副業で一番危ないのがここです。

- 家電メーカー勤務 → 家電の外観デザインは受けない
- 文具メーカー勤務 → 文具のデザインは受けない
- 迷ったら「本業の取引先・競合他社が発注者になりうるか」で判断する

僕が線を引いたのは【要記入: 自分のルール。例「自社が扱うカテゴリの製品デザイン全般は受けない。ロゴ・3Dレンダー・他ジャンルの製品のみ」】です。
**受けなかった案件** の例: 【要記入: 例「競合メーカーの下請けからの外観デザイン依頼。単価は良かったが断った」】

## 3. 守秘とポートフォリオ：本業の成果物は使わない

- 本業のデザイン（未発表はもちろん、発売済みでも）を副業の実績として載せない
- 社内で得た情報（コスト・工場・素材の仕入れ先）を副業に使わない
- 副業用のポートフォリオは **自主制作と副業の実績だけ** で作る

実績ゼロ問題は、自主制作で埋めます。水曜の記事のフロー（手描き→AI→3D→CAD）を、架空の製品で1回通すと、そのまま作例になります。

## 4. ツールと機材：会社のライセンス・PCで副業しない

見落としがちですが、デザイナーには特に重要です。

| もの | NG | OK |
|------|----|----|
| Adobe / CAD / KeyShot | 会社契約のライセンス | 個人で契約したライセンス（商用利用できるプランか確認） |
| PC・ペンタブ | 社用PC・会社の機材 | 私物 |
| 生成AIツール | 会社契約のアカウント | 個人アカウント（利用規約の商用条件を確認） |
| フォント・素材 | 会社が契約しているもの | 個人で商用ライセンスを持つもの |

たとえば Fusion の個人版（Personal Use）は非商用利用が前提なので、売上が発生する副業では条件に当たらない可能性があります。**個人で買うツールは「商用可か」を必ず確認** してください。

## 5. 時間：本業に支障を出さない上限を決める

- 平日の副業は何時まで、週何時間まで、を先に決める
- 納期は本業の繁忙期を避けて設定する（ココナラならお届け日数を長めに）
- 雇用契約（アルバイト等）で副業する場合は、本業と労働時間が通算されるので会社への申告が必要になります。業務委託（ココナラなど）はこれと扱いが違うので、詳しくは厚労省のガイドラインと会社のルールを確認してください

僕の上限は【要記入: 例「平日は22時まで・週8時間まで。本業の量産立ち上げ期は受注を止める」】です。

## 6. 税金：「20万円」は売上ではなく所得

副業の話で一番誤解が多いのがこれです。

| よくある理解 | 正しくは |
|--------------|----------|
| 副業の **売上** が20万円以下なら申告不要 | 副業の **所得（売上 − 経費）** で判断する |
| 20万円以下なら何もしなくていい | **所得税** の確定申告は原則不要でも、**住民税** の申告は別に必要 |
| 誰でも20万円ルールが使える | 給与が1か所で年末調整を受けている人などの条件がある |

国税庁の説明では、給与を1か所から受けていて年末調整を受けている人は、給与・退職所得以外の所得の合計が20万円以下なら、原則として所得税の確定申告は不要です（2026年9月時点）。ただし医療費控除などで確定申告をする場合は、20万円以下でも副業の所得を含めて申告します。

**やっておくこと**
- 売上と経費を最初から記録する（ココナラの取引明細＋経費のレシート）
- 手数料（ココナラなら販売価格の22%）も経費として整理しておく
- 迷ったら税務署か税理士に相談する

## 7. 住民税：本業の会社に伝えたうえで、納付方法を確認する

副業の所得があると、翌年の住民税が増えます。確定申告書には、副業分の住民税を **給与から天引き（特別徴収）するか、自分で納付（普通徴収）するか** を選ぶ欄があります。ただし扱いは自治体によって異なるので、お住まいの市区町村に確認してください。

ここで大事なのは、**住民税の納付方法を「会社に知られないための手段」として考えないこと**。項目1で会社に申請・相談を済ませていれば、どちらを選んでも困りません。

## 上司・人事への相談文面（例）

```
件名：副業（個人でのデザイン業務）開始のご相談

〇〇さん

お疲れさまです。〇〇です。
就業規則第〇条に基づき、副業についてご相談させてください。

■ 内容：個人向けの3Dレンダー作成・製品スケッチ（オンラインのスキル販売サービス経由）
■ 時間：平日20〜22時・休日の一部、週8時間以内。本業に支障が出る時期は受注を止めます
■ 競業：当社の取扱カテゴリ（〇〇）および競合他社・取引先からの依頼は受けません
■ 守秘：当社の成果物・社内情報は一切使用せず、実績としても公開しません
■ 機材：私物のPC・個人契約のソフトウェアのみを使用します

申請書の様式があればご教示ください。よろしくお願いいたします。
```

先に「4つの制限事由（支障・秘密・信用・競業）に当たらない理由」を書いておくと、相談がスムーズになります。

- [ ] 1. 就業規則の副業条項（禁止 / 許可制 / 届出制）と申請様式を確認した
- [ ] 2. 受けない案件ジャンル（競業）を決めた
- [ ] 3. 本業の成果物・社内情報を使わないと決め、自主制作でポートフォリオを作った
- [ ] 4. 会社のライセンス・PC・アカウントを使わず、個人ツールの商用可否を確認した
- [ ] 5. 副業の時間上限と、止める時期を決めた
- [ ] 6. 売上と経費の記録を始めた（20万円は所得で判定）
- [ ] 7. 住民税の申告・納付方法を自治体に確認した
