# デザインレビュー用A3提案シートのテンプレ 12カラムの寸法表と記入例

デザインレビュー（DR）のA3資料を毎回ゼロからレイアウトして半日かかり、そのうえ「で、何を決めればいいの？」と差し戻される。原因は図版の出来より、見る側が探す欄の位置が毎回変わることにあります。この記事では「決めてほしいこと」を左上に固定したA3横・12カラム×6段のテンプレを、寸法表・欄の座標・文字スタイル・Illustratorの手順・記入例・提出前チェックリストまで渡します。

## 1. 読者の悩み：半日かけたA3が「で、何を決めればいいの？」で返ってくる

入社2年目、初めて自分の案だけでDRに出ることになったとします。

前の日の午後から、Illustrator で新規ドキュメントを開き、A3横にレンダリングを大きく置いて、コンセプトの文章を添えて、寸法を入れて……と、配置を決めるだけで半日。やっとPDFにして会議室のモニタに映すと、課長からは「で、今日は何を決めればいいの？」、設計の担当からは「外形寸法どこに書いてある？」、企画からは「前回から何が変わったの？」。

図版をほめられる時間はほとんどなく、質問に答えているうちに時間切れ。「次回までに整理して再提出で」と言われて席に戻る。次のDRでもまた、白紙のアートボードからレイアウトを始める。この記事は、その繰り返しから抜けるための記事です。

## 2. 結論：「決めてほしいこと」を左上に固定した、A3横・12カラム×6段のテンプレを1回だけ作る

- **欄の位置を固定する**：左上に「このDRで決めてほしいこと」、右上に「前回からの変更点」、右列に「主要寸法」「CMF・コストの前提」「懸念と対策」、右下に「次のアクション」。図版はその間に置く
- **数値で作る**：A3横（420×297mm）、外周15mm、12カラム（幅27mm・ガター6mm）×6段（高さ35mm・間隔6mm）。12列なら3案を4列ずつ横に並べられる
- **紙と画面の両方で読めるサイズにする**：注記は8pt以上、A4に縮小されるなら10pt以上。Illustrator の段落スタイルに登録し、テンプレート（.ait）で保存して毎回そこから始める

テンプレを1回作れば、次からはレイアウトを考える時間がなくなり、見る側は毎回同じ場所を見れば判断材料が見つかります。作る時間と探す時間の両方が減る、というのがこの記事の答えです。

## 3. 背景：図版はきれいなのに差し戻される3つの理由

### 理由1：見る側は「作品」ではなく「判断材料」を探している

DRは作品の発表会ではなく、次の工程に進むかどうかを決める場です。出席者はそれぞれ、自分の担当の判断に必要な情報を探しながら1枚目を見ます。このテンプレを組むときに置いた想定は次のとおりです（部署構成は会社によって違います）。

| 出席者（想定） | 1枚目で最初に探すもの | 見つからないと出る質問 |
|---|---|---|
| 上司（課長・部長） | 今日、自分が何を決めればいいか | 「で、何を決めればいいの？」 |
| 設計 | 外形寸法・内部部品との関係・分割 | 「寸法どこ？」「これ入るの？」 |
| 企画 | 前回からの変更点・コストの前提 | 「前回と何が違うの？」 |
| 品証・生産 | 懸念点とその対策 | 「ここ、試験は大丈夫？」 |

学生時代のプレゼンボードは「見せる」ためのレイアウトなので、図版が主役で、判断材料の欄はありません。その型のままDRに出すと、図版の出来とは関係なく、表の右側の質問が毎回出ます。

### 理由2：毎回ゼロからレイアウトするので、欄の位置が毎回変わる

資料ごとに寸法の位置が右下だったり左下だったりすると、見る側は毎回探すところから始めます。作る側も、配置を決めるところから始めるので時間がかかる。テンプレにする価値は「きれいにそろう」ことより、**作る時間と探す時間の両方が減る**ことにあります。

### 理由3：紙と画面の両方で読まれるのに、片方だけで作っている

社内DRでは、A3の資料を16:9のモニタに映したり、A4に縮小して配ったりすることがよくあります。どちらも文字が小さくなります。計算するとこうなります。

| 条件 | 計算 | 8ptの文字 | 10ptの文字 |
|---|---|---|---|
| A3横を1920×1080の画面に全体表示 | 高さ297mm→1080px＝約3.6px/mm。表示幅は約1527px（画面幅の約80%） | 約10px | 約13px |
| A3をA4に縮小して印刷 | 1/√2＝約70.7%（コピー機の「71%」） | 約5.7pt | 約7.1pt |

（1pt＝約0.353mmで計算。画面の値はビューアのツールバー等を除いた、全体表示時の上限です）

Illustrator 上で100%表示にして作っていると、8ptの注記は普通に読めます。ところが会議室のモニタでは10px前後になり、A4配布では6pt弱になる。「寸法どこ？」と聞かれる理由の一部は、書いてあるのに読めないことです。

## 5. 具体例：完成見本の構成図（架空の卓上加湿器・案D）

<!-- 完成見本（案シート・判断シート）の縮小画像：公開時に挿入（PNG。架空製品で作成したもの） -->

案1つを1枚にまとめる「案シート」の構成です。A3横を12カラム×6段に割り、左8列を図版、右4列を判断材料にしています。

```
+--------------------------------------------------+------------------------+
| A 案名＋コンセプト1行（24pt）                    | 管理欄 DR名/日付/版数  |
|                                                  | 機密表記               |
+--------------------------------------------------+------------------------+
| B この案で決めてほしいこと（14pt）               | C 前回からの変更点     |
|                                                  |                        |
+--------------------------------------------------+------------------------+
| D メイン図版                                     | E 主要寸法             |
|   レンダリング／スケッチ（3段分）                |   外形・簡易三面図     |
|                                                  |                        |
|                                                  |------------------------|
|                                                  | F CMF・コストの前提    |
+--------------------------------------------------+------------------------+
| G サブ図版（使用シーン4コマ）                    | H 懸念と対策           |
+--------------------------------------------------+------------------------+
| I 評価と選んだ理由（1行説明）                    | J 次のアクション       |
+--------------------------------------------------+------------------------+
```

欄の置き方には、それぞれ理由があります。

- **B「決めてほしいこと」を図版より上に置く**：問いを読む前に図版を見ると、コメントが「この角のRが好き／嫌い」になりやすい。問いを先に読んでもらうと、図版を「問いに答える材料」として見てもらえます
- **右列（C・E・F・H）は上から「変更点→寸法→前提→懸念」の順**：理由1の表で、企画・設計・品証がそれぞれ探すものを、毎回同じ場所に置きます
- **J「次のアクション」を右下に置く**：会議の最後に見る場所です。ここが空欄だと、決まったことが議事録にしか残りません

B欄の記入例（架空）はこうなります。

> **この案で決めてほしいこと**
> ① 案D（給水口を正面に移した案）で、設計の内部配置検討に進めてよいか
> ② 進める場合、天面の操作部（案Aから移植）を残すか、正面にまとめるか

問いを「〜してよいか」「AかBか」の形で終えると、DRの場で「はい／いいえ」か選択で答えてもらえます。

## 6. 方法：テンプレづくりの全体像（7ステップ）

1. **出力先を決める**：画面共有だけか、社内プリンタでA3に出すか、印刷所に出すか。これでカラーモードと解像度が決まる
2. **新規ドキュメントを作る**：A3横・アートボード2枚（判断シート／案シート）。設定をプリセットとして保存
3. **グリッドを引く**：版面390×240mmを「グリッドに分割」で12列×6段に分け、ガイドにしてロック
4. **欄の枠を置く**：案シート・判断シートの各欄を座標どおりに配置
5. **文字の設定を登録する**：段落スタイル5つ・文字スタイル1つ
6. **くり返し使う部品をシンボルにする**：評価マーク・機密表記・寸法の矢印
7. **記入例で確かめて保存する**：画面とA4で読めるか確認し、テンプレート（.ait）で保存

ここまでで、何をどこに置くかと、なぜそこに置くかは全部出しました。自分でゼロから組むこともできます。ただ、実際にIllustratorで組もうとすると「カラムの幅とガターを何mmにすれば割り切れるか」「欄ごとのX・Y座標」「文字は何ptで何行送りか」「出力先ごとの設定」を1つずつ決める必要があり、そこで手が止まります。有料部分では、その数値をすべて決めた状態で渡します。

| DR_本文 | 段落 | 10pt／15pt | C・F・H・I・J・M・N | 約13px | 約7.1pt |
| DR_注記 | 段落 | 8pt／12pt | E 寸法の数値、管理欄、図版の注記 | 約10px | 約5.7pt |
| DR_強調 | 文字 | 太字＋強調色1色 | 本文中の数値・「決まったこと」 | － | － |

- 画面の値は「pt×0.353mm×3.64px/mm」、A4の値は「pt×0.707」で計算しています
- **A4に縮小して配る可能性があるなら、DR_注記も10ptにする**（A4で約7.1pt）。8ptのままだとA4で約5.7ptになります
- フォントは、社内で決まっているものがあればそれを使います。無ければ、資料を開く人のPCでも表示できるフォントを選び、PDF書き出し時に埋め込まれているか確認します
- 行送りはサイズの1.3〜1.5倍にしています。欄の高さ35mmに、DR_本文（10pt／15pt）なら約6行入ります（15pt≒5.3mm）

## 6-4. 出力先別の設定値：画面共有／社内プリンタ／印刷所

| 出力先 | カラーモード | ラスタライズ効果 | PDF書き出し | 注意 |
|---|---|---|---|---|
| 画面共有・PDF配布だけ | RGB | 目安150ppi（Illustratorの既定は画面用72ppi／印刷用300ppi。72ppiだとぼかしや影が粗く見えることがあるので中間をとった目安） | 図版を見せるなら「高品質印刷」。「最小ファイルサイズ」はWeb・メール向けで画質が下がる | 全体表示で8pt＝約10px |
| 社内プリンタでA3出力 | CMYK | 300ppi | 「高品質印刷」（カラー画像は300ppiにダウンサンプル） | 外周15mmがプリンタの印字範囲に収まるか、1枚出して確認 |
| 印刷所（展示会パネル等） | CMYK | 300ppi以上 | 印刷所の指定のプリセット | 塗り足し3mm、画像は原寸で350〜400dpi（ラクスルの入稿仕様の例） |

- 画面でも紙でも使う場合は、紙（CMYK）に合わせます。RGBの鮮やかな色はCMYKで再現できないので、RGBで作って刷ると色がくすみます
- カラーパネルの表示をCMYKに切り替えても、**ドキュメントのカラーモードは変わりません**。変えるのは「ファイル＞ドキュメントのカラーモード」です
- PNGで書き出すときのピクセル数：A3横・300ppiで約4961×3508px、150ppiで約2480×1754px

## 6-5. Illustratorでの作り方：全ステップ

メニュー名は Adobe のヘルプで確認した表記です（一部は英語版ヘルプからの訳）。無料部分の7ステップのうち、2〜7をIllustratorの操作単位で9つに分けています（1の出力先は6-4の表で決めます）。バージョンやOSで名前・位置が変わることがあります（僕の環境は第4章に書いたとおりです）。

**ステップ1：新規ドキュメントを作る**
1. 「ファイル＞新規」を開き、「印刷」のタブからA3を選ぶ
2. 方向を横、単位をミリメートルにし、幅420・高さ297になっていることを確認する
3. アートボードの数を2にする。裁ち落としは社内出力なら0、印刷所に出すなら3mm
4. カラーモードとラスタライズ効果を、6-4の表の出力先の行に合わせる

完了条件：アートボードが2枚あり、どちらも420×297mm。

**ステップ2：設定をプリセットとして保存する**
1. 手順1の設定のまま、ダイアログの保存ボタンでプリセットに名前を付ける（例：「DR_A3横_CMYK_300」）
2. 画面共有用も作るなら「DR_A3横_RGB_150」を別に保存する

完了条件：次に「ファイル＞新規」を開いたとき、「保存済み」にプリセットが出る。

**ステップ3：アートボードとレイヤーに名前を付ける**
1. アートボードパネルで1枚目のアートボードオプションを開き、名前を「00_判断シート」にする。2枚目は「01_案シート」
2. レイヤーを3つ作り、下から「_grid」「frame」「content」と名前を付ける

完了条件：書き出し時にアートボード名がファイル名に入り、どれが判断シートか分かる。

**ステップ4：グリッドを引く**
1. 「_grid」レイヤーを選び、長方形ツールで適当な長方形を描く
2. 変形パネル（またはプロパティパネル）で基準点を左上にし、X15・Y42・W390・H240 と入力する
3. 「オブジェクト＞パス＞グリッドに分割」を開き、行を「段数6・高さ35・間隔6」、列を「段数12・幅27・間隔6」にする
4. 「ガイドを追加」にチェックを入れてOKを押す
5. ヘッダー帯として、X15・Y15・W390・H21 の長方形を描き、選択したまま「表示＞ガイド＞ガイドを作成」でガイドにする
6. 「表示＞ガイド＞ガイドをロック」でガイドを固定する。分割されたセル（72個の長方形）は「_grid」レイヤーに置いたままロックし、書き出し前に非表示にする
7. 2枚目のアートボードにも同じ手順でグリッドを引く（座標が1枚目の位置になってしまう場合は、定規がアートボードごとの設定になっているか確認する）

完了条件：「グリッドに分割」の合計欄が幅390・高さ240になっていて、X279・Y83の位置にガイドの交点がある。

**ステップ5：欄の枠を置く**
1. 「frame」レイヤーで、6-2の表のX・Y・幅・高さどおりに長方形を描く（塗りなし、線0.3pt・グレー）
2. 各枠の左上に、欄の名前（「決めてほしいこと」「前回からの変更点」など）を置く
3. 枠の中には、6-2の「書く内容」を仮の文章として入れておく（使う人が消して書き換える）

完了条件：案シートに11枠、判断シートに11枠。すべての枠の角がガイドに吸着している。

**ステップ6：段落スタイルと文字スタイルを登録する**
1. 「ウィンドウ＞書式＞段落スタイル」を開く
2. 6-3の表のサイズ・行送りでテキストを1つ作り、選択したまま段落スタイルパネルで新規スタイルを作る。これを DR_タイトル／DR_問い／DR_欄見出し／DR_本文／DR_注記 の5つぶんくり返す
3. 「ウィンドウ＞書式＞文字スタイル」で DR_強調（太字＋強調色）を作る
4. ステップ5の見出しと仮の文章に、それぞれのスタイルを当てる

完了条件：テンプレ内のすべてのテキストに、5つの段落スタイルのどれかが当たっている。

**ステップ7：くり返し使う部品をシンボルにする**
1. 「ウィンドウ＞シンボル」を開く
2. 評価マーク（◎・○・△）、機密表記のスタンプ、寸法の矢印をそれぞれ作り、シンボルパネルの「新規シンボル」にドラッグして登録する（Alt／Optionを押しながらドラッグするとダイアログを省ける）
3. 管理欄の機密表記と、I欄の評価マークをシンボルに置き換える

完了条件：シンボルパネルに5つ（◎・○・△・機密表記・矢印）が並んでいる。シンボルを1つ直すと、テンプレ内の同じ部品がすべて変わる。

**ステップ8：記入例で確かめる**
1. 6-6の記入例を判断シートに入れる
2. PDFで書き出し、1920×1080のモニタで全体表示する。DR_注記が読めるか見る
3. 同じPDFをA4に縮小して1枚印刷し、E欄の寸法が読めるか見る
4. 読めなければ DR_注記を10ptに上げる（スタイルを直せば全部変わる）

完了条件：モニタの全体表示とA4印刷の両方で、E欄の数字が読める。

**ステップ9：テンプレートとして保存する**
1. 記入例を消し、仮の文章だけが入った状態にする
2. テンプレート形式（.ait）で保存する。メニューの場所：【要記入: 本人のIllustratorで確認した .ait の保存メニュー表記（バージョンで違うため）。例）ファイル＞テンプレートとして保存】
3. 記入例を入れた版は別に .ai と PDF で保存しておく（見本用）
4. PDFは「Adobe PDF」で保存し、プリセットは6-4の表の出力先に合わせる

完了条件：.ait をダブルクリックすると名前の無い新規ドキュメントとして開き、元の .ait は変わらない。

## 6-6. 記入例：架空の卓上加湿器（判断シート）

水曜の記事で12案から絞った3案（D・B・K）を、そのまま判断シートに入れた例です。**製品・数値はすべて架空**です。

| 欄 | 記入例 |
|---|---|
| A 議題 | 卓上加湿器リニューアル（仮称）第1回DR：設計検討に進む1案を決める |
| 管理欄 | DR1／2026-10-02／v01／作成：デザイン◯◯／社外秘 |
| K 決めてほしいこと | ① D・B・K のうち、設計の内部配置検討に進める1案を選んでください　② D を選ぶ場合、天面の操作部（案Aから移植）を残してよいか |
| L1〜L3 図版 | 3案とも斜め上30°のレンダリング、同じ縮尺、背景は薄いグレー |
| M1 案Dの要点 | 給水口を正面に移し、置いたまま給水できる／タンク・ヒーターは現行流用、コストは現行比+3%の見込み／懸念：給水口まわりの水だれ |
| M2 案Bの要点 | 天面の稜線で店頭での差が最も大きい／コストは現行比+5%の見込み（上限ぎりぎり）／懸念：稜線部の成形でヒケが出ないか |
| M3 案Kの要点 | 横長にして、奥行きの浅い棚にも置ける／コストは現行比+4%の見込み／懸念：横長にしたときの転倒安定性 |
| N 推奨と理由 | 推奨はD。足切り4項目を通過した6案のうち、給水のしやすさで最上位のD（Aの操作部を移植）と、店頭の差で最上位のB。Kは横長形状が置き場所の問題を解くかを確かめる振り幅 |
| J 次のアクション | Dの場合：設計と内部配置の干渉確認（2週間）→DR2で外観三面図とCMF3色／Bの場合：成形の相談を先に実施／Kの場合：転倒試験の条件を品証と確認 |

案シートの C「前回からの変更点」は、2回目のDRから次のように書きます。

> v01→v02：DR1の指摘「給水口が正面だと水だれが見える」→ 給水口の下に幅3mmの受け溝を追加（E欄の三面図に赤で表示）

「指摘→変えたこと→どこを見ればいいか」の3つを1行に入れると、企画の「前回と何が違うの？」に図を指さして答えられます。

## 7. 失敗：体裁は整ったのに、読まれない・刷れない

【要記入: DR資料のレイアウトや出力で本人が実際にした失敗1〜2つ。何が起きて、どれだけ損したか（作り直した時間・DRの延期・印刷のやり直し枚数など）。例）RGBで作ったA3を社内プリンタで出したら赤が茶色っぽくなり、DRの30分前に刷り直した】

ここからは、**よくある失敗**として、このテンプレの数値を決めるときに避けたものを4つ挙げます（本人の体験ではなく、一般的に起きやすい例です）。

| 失敗 | 何が起きるか | 原因 |
|---|---|---|
| A 色がくすむ | RGBで作ったA3を社内プリンタで出すと、強調色やレンダリングが沈んだ色になる。CMFの色を決めるDRだと色の話ができない | RGBの鮮やかな色はCMYKで再現できない。カラーパネルの表示をCMYKにしただけで、ドキュメントはRGBのままだった |
| B 注記が読めない | 寸法を書いてあるのに「寸法どこ？」と聞かれ、拡大して説明する時間が毎回かかる | Illustratorの100%表示で文字サイズを決めていた。1920×1080の全体表示では8ptが約10pxになる |
| C 比べてもらえない | 3案のアングル・縮尺・背景が違い、「形の差」ではなく「絵の差」で選ばれる | 案ごとに別のファイルで、別の日にレイアウトしていた |
| D 原本の上書き | 前回のDRの .ai をテンプレ代わりに使い回し、消し忘れた前回の数値がそのまま出る。原本も崩れていく | テンプレを .ai のまま共有フォルダに置いていた |

## 10. まとめ

- DRで差し戻される原因は、図版の出来より「見る側が探す欄が見つからない」こと。「決めてほしいこと」を左上、判断材料を右列に固定する
- A3横・外周15mm・12列（27mm／ガター6mm）×6段（35mm／間隔6mm）で組めば、3案比較も1案1枚も同じグリッドで作れる
- 文字は画面の全体表示とA4縮小の両方で確かめる。注記8ptは画面で約10px、A4で約5.7pt

**次の1アクション**：次のDRの「決めてほしいこと」を、2行以内の問いの形で書いてみてください。テンプレを作るのはその後で間に合います。問いが決まれば、判断シートのどこに何を置くかは6-2の表どおりです。
