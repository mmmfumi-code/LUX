# 【副業の道具箱】AIプロンプト図鑑400｜貼るだけでチラシ・動画・結婚式ムービーまで

（画像：01_サムネイル.png は見出し画像に設定）

こんにちは、【要記入：名前・肩書き。例：メーカーで働きながら、副業でデザインをしている〇〇です】。

「AIを使えば副業ができる」
そう聞いて ChatGPT を開いてみたものの、

- 何を作って売ればいいのか分からない
- それっぽい画像や文章は出るけど、お客さんに出せるレベルにならない
- 毎回、指示の書き方を考えるだけで時間が過ぎる

そんな状態で止まっていませんか？

AIの答えの質は、**最初に送る指示（プロンプト）で、ほぼ決まります**。
裏を返せば、「仕事で使えるレベルの指示」さえ手元にあれば、AIは副業の強力な相棒になります。

そこで、副業で**実際にお金をいただける成果物**（チラシ、名刺、SNS動画、資料、ホームページ、結婚式のムービーなど）に絞って、コピーして貼るだけで形になるプロンプトを **9ジャンル・400本** まとめました。

## この図鑑を作った背景

【要記入：作者自身のきっかけ（実際の体験だけ）。例：副業でデザインの依頼を受けるようになって、AIを使い始めたときに困ったこと／毎回プロンプトを考える時間がかかっていたこと など。数字があれば添える】

この図鑑は、次の3つを大事にして作りました。

**1. 「仕事で納品できる」細かさで書く**
「おしゃれなチラシを作って」ではなく、「上部に赤い帯、黄色の極太文字で〇〇、価格は商品名の3倍の大きさ」のように、デザイナーが外注先に指示を出すときの細かさで書いています。

**2. 失敗したときの「一言」まで入れる**
「文字が崩れた」「安っぽい」「もっと短く」など、よくある失敗に対して、そのまま送れる追加の指示を各ジャンルに付けています。AIとのやりとりで迷う時間が減ります。

**3. 権利まわりで困らないようにする**
実在のブランド名・ロゴ・キャラクター・音楽は使わない指示を、最初から入れています。お客さんに納品する前提だからこそ、ここは外せませんでした。

## 副業に、どう活かすか

（画像：05_副業メニュー.png）

この図鑑は「プロンプト集」ですが、本当の使い道は**副業のメニューづくり**です。たとえば、こんな仕事を受けられるようになります。

- **チラシ・名刺・バナーの制作**（グラフィック）
- **SNS投稿・ショート動画の編集、テロップ入れ**（動画編集・モーション）
- **結婚式のオープニング・プロフィールムービー**（ウェディング）
- **事業計画書・営業資料の作成**（プレゼン）
- **小さなお店のホームページ**（ホームページ）
- **写真からの似顔絵・アイコン**（イラスト）

そして、**マーケティングの10本**は、あなた自身の副業の戦略を考えるためにも使えます。「どの仕事を、いくらで、誰に売るか」を、AIと一緒に整理できます。

## 「月10万円」は、こう分けて考える

（画像：06_月10万円の考え方.png）

副業で月10万円と聞くと大きく感じますが、**1つで10万円をめざさず、小さな仕事を組み合わせる**と現実的になります。

| 仕事 | 単価 | 件数 | 合計 |
|---|---|---|---|
| チラシ・バナー制作 | 5,000円 | 6件 | 30,000円 |
| 名刺・ショップカード | 3,000円 | 5件 | 15,000円 |
| ショート動画の編集 | 3,000円 | 5本 | 15,000円 |
| プロフィールムービー | 20,000円 | 2件 | 40,000円 |
| **合計** | | | **100,000円** |

※ これは計算の例で、作者の実績ではありません。価格は出品するサービスの相場を確認して決めてください。販売サービスの手数料は別にかかります。

**進め方の目安**

1. **最初の1か月**：自分用・家族や知人用に作って、作例（ポートフォリオ）を10点そろえる
2. **2〜3か月目**：ココナラなどのスキル販売サービスに2〜3品を出品。まずは月1〜3万円を目標に
3. **4か月目〜**：評価がついたら、少しずつ値上げ・リピートのお願い・メニューの追加

正直に言うと、**プロンプトを持っているだけでは稼げません**。出品・やりとり・修正・納品は、あなたの仕事です。この図鑑は、その中のいちばん時間がかかる「作る」部分を、ぐっと短くするための道具です。

## 無料で使えるお試しプロンプト

ここで1本、そのまま使えるプロンプトを公開します。副業の方向性を決めるのにも使える「事業の健康診断」です。ChatGPT か Claude に貼って、【私の情報】を分かる範囲で埋めて送ってみてください。

```
あなたは、個人事業主や小さなお店を何百件も支援してきた、経験豊富なマーケティングの相談相手です。次の【相談内容】について、一緒に分析と戦略を考えてください。

【進め方のルール】
・最初に、分析に必要なのに【私の情報】に書かれていないことを、3〜5個だけ質問してください。私が答えてから本題に入ります（「このまま進めて」と言われたら、仮の前提を置いて進めてください）
・私は1人で事業をしています。予算も時間も限られているので、大企業向けではなく「1人で、少ないお金で、今日から動ける」提案にしてください
・数字や事実を作らないでください。分からない数字は【要確認】と書いてください
・最後に必ず「今週やること」を3つ、かかる時間の目安と一緒に書いてください

【相談内容】
私の副業の「健康診断」をしてください。今の状態を整理して、どこに力を入れるべきかを一緒に見つけたいです。
1. 3C分析：お客さま・競合・自分を、それぞれ箇条書きで整理
2. SWOT分析：強み・弱み・機会・脅威を2×2の表に
3. 「強み×機会」でいちばん伸ばせそうなことを1つ選び、理由を説明
4. 今の弱点のうち「放っておくと危ない」ものを1つだけ挙げ、小さな対策を提案

【私の情報】
・副業の内容（何を・誰に・いくらで）：
・始めてからの期間：
・月の売上の目安と、目標：
・得意なこと・好きなこと：
・困っていること：
```

これと同じ考え方で作ったプロンプトが、あと399本入っています。

## 使い方は3ステップ

（画像：07_使い方.png）

1. **選ぶ**：見本を見ながら、作りたいものに近いプロンプトを選ぶ
2. **貼る**：「プロンプトをコピー」を押して、ChatGPT や Claude に貼って送る
3. **直す**：気になる所は「うまくいかないとき」の一言を送る

画像系は ChatGPT（画像生成）、資料・ホームページ・動画・分析系は Claude か ChatGPT がおすすめです。
