### 最初に「プロダクトの翻訳メモ」を作る
デザインを始める前に、次を1枚にまとめる（成果物の冒頭に載せる）。
- 一言でいうと何の商品か／誰のためか／何が一番の価値か
- 守るべきデザイン意図（例: 「細身で軽い」「継ぎ目の少なさ」）
- 製品の CMF（色名・HEX・素材・仕上げ）
- 広告で伝える主な便益（機能 → ユーザーにとっての意味）

## 2. プロダクトデザイナーの意図を壊さない（Product Integrity）

すべての方向・すべての展開物で守る。
- **製品の色・形・プロポーションを変えない**（色味を加工しない、変形・引き伸ばしをしない）
- 製品の特徴的なディテール（デザイン意図の中心）を、文字や装飾で隠さない
- 広告のカラーパレットは製品の CMF と調和させる（製品の色を背景に展開する、補色で引き立てる など、理由を書く）
- 製品が持つトーン（ミニマル／温かい／上質 など）と逆の世界観にしない。C で意外性を出す場合も、デザイン意図と矛盾させない
- 採用案に無い機能や効果を広告で約束しない（誇大表現・根拠のない効果効能はNG）

## 3. 3方向の定義

| 方向 | 狙い | 表現の主役 | コピーの方向 | 写真・光の例 |
|---|---|---|---|---|
| **A: ブランド王道** | 信頼・品質・ブランドらしさを最短で伝える | 製品そのもの（ヒーローショット） | 便益を明快に。ブランドの約束を言い切る | 無地背景のスタジオ撮影、柔らかく均一な光 |
| **B: エモーショナル** | 使う人の気持ち・時間・暮らしに共感させる | 人・シーン・瞬間（製品は自然に存在） | 情景・感情に語りかける | 自然光、時間帯（朝・夕）の色温度、手元や生活の気配 |
| **C: コンセプチュアル** | 商品の本質をアイデアで象徴し、記憶に残す | 抽象・メタファー・グラフィックの仕掛け | 短く、発見のある一言 | 強いコントラスト、造形的な光と影、グラフィックとの合成 |

3方向は、色・書体・レイアウト・写真のトーンがはっきり違うこと。ただし3方向とも「採用プロダクト」と「ブランド」は同じであることが伝わること。

## 4. 各方向で定義するデザインシステム

各方向について、次の6要素を **ルールとして** 定義する（「なんとなく」ではなく、再現できる数値・条件で）。

| 要素 | 定義する内容 |
|---|---|
| **Typography** | 役割別の書体（メインコピー／欧文・ラベル／本文。最大3書体）、ウェイト、字間・行間、大きさの比率、縦組み・横組み、禁止事項。書体は Google Fonts などライセンス上問題ないもの |
| **Color** | パレット（最大6色、HEX・名前・役割）、**面積比（%）**、製品の CMF との関係、背景と文字のコントラスト（WCAG AA 以上）、使ってはいけない組み合わせ |
| **Layout** | グリッド、余白（キャンバス短辺に対する比率）、製品とコピーの位置関係、ロゴ・CTA の位置、縦長・横長・正方形での組み替えルール |
| **Photography** | 撮影スタイル、アングル、構図、被写体（製品のみ／人物／手元／シーン）、背景、小物、レタッチの方針 |
| **Lighting** | 光源の種類と数、方向、硬さ（ソフト／ハード）、色温度、影の出し方、ハイライトの入れ方 |
| **Graphic Motif** | 方向の個性を作る図形要素（製品の形・構造から抽出するのが基本）、使い方のルール、使いすぎの禁止 |

## 5. 各方向の展開物

同じデザインシステムで、次の6点を制作する。

| 展開物 | ファイル | サイズ |
|---|---|---|
| Key Visual | `kv.html` → `kv.png` | 1920×1080 |
| 広告コピー | 成果物の md に記載（メイン・サブ・ボディ・CTA、各2〜3案から推奨1案） | — |
| ポスター | `poster.html` → `poster.png` | 1414×2000（B2 などA/B判の比率） |
| SNS広告 | `sns-feed.html`（1080×1350）、`sns-story.html`（1080×1920） | 4:5、9:16 |
| ECバナー | `ec-banner.html` → `ec-banner.png` | 1200×628 |
| Web Hero | `web-hero.html` → `web-hero.png` | 1920×1080 |

### 制作の手順
1. 共通キット `templates/graphic/` を `graphic/vN/<A|B|C>/` にコピーする（`tokens.css`、`apps.css`、6つの HTML）
2. **`tokens.css` に、その方向の Color・Typography・Layout・Graphic Motif を定義する**。6つの展開物はすべてこの値を参照するので、ここを決めれば全媒体の統一感が保たれる
   - 書体を変えたら、各 HTML の `<link id="fonts">`（Google Fonts）に書体を追加する
   - Graphic Motif は SVG で作り（`motif.svg` など）、`--motif: url("motif.svg")` で指定する
3. 製品の画像を用意する: 採用案のメインビジュアルを **背景を透明にした PNG** にする
   - SVG の場合: `node scripts/render.mjs png <design-XX.svg> graphic/vN/A/product.png --width 1600 --height 1600 --scale 1 --transparent`
   - 方向ごとに写真のトーンが必要な場合（B の生活シーンなど）は、画像生成AI用のプロンプトを `prompts/06-graphic-<A|B|C>-<用途>.md` に保存する。プロンプトには Photography と Lighting の定義を反映し、末尾に必ず `no text, no letters, no typography, no logo, no watermark` を入れる。製品の形・色を変えないことも明記する
4. HTML のコピー・レイアウトを方向に合わせて調整する（キットの配置は出発点。方向の Layout ルールに合わせて変えてよい）
5. 書き出す: `bash scripts/render-apps.sh graphic/vN/A`（6点を所定のサイズで PNG に）
6. 書き出した PNG を目で確認する（文字の欠け・製品との重なり・コントラスト・セーフエリア）

### 画像とテキストの分離（厳守）
- 画像（写真・イラスト・製品ビジュアル）の中に日本語の文字を描き込まない
- コピー・ロゴタイプ・CTA などの文字は、すべて HTML/CSS で組む

## 6. A3プレゼンボード（各方向1枚＋一覧1枚）

各方向を A3横（420×297mm）のボードにする。レイアウトは共通テンプレート（`layout: "graphic"`）を使う。

- ボードの内容: 方向性、広告コピー、Typography（実際の書体で見本を表示）、Color（面積比のバー＋色見本）、Layout（グリッド図）、Photography／Lighting（参考図）、Graphic Motif、Key Visual、展開物（ポスター・SNSフィード・ストーリー・ECバナー・Web Hero）
- 手順:
  1. ボード用の図を用意する（文字なし）: レイアウトのグリッド図 `graphic/board/vN/img/layout-<A|B|C>.svg`、写真・ライティングの参考図 `photo-<A|B|C>.svg`（または生成画像）、モチーフの見本 `motif-<A|B|C>.svg`
  2. `graphic/board/vN/boards.json` を書く（見本: `templates/board/example-graphic/boards.json`。`"layout": "graphic"`、各方向 `no` は `A` `B` `C`）
  3. `node scripts/board.mjs graphic/board/vN/boards.json`
  4. 出力: `board-A/B/C.(html|png|pdf)`、`overview.(png|pdf)`（3方向の比較）、`boards-all.pdf`
  5. 「⚠」（文字数超過・画像欠落・あふれ）が出なくなるまで直し、PNG を目で確認する
