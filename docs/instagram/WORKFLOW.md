# INSTAGRAM CONTENT WORKFLOW

対象アカウント：[@fumiya_mainac](https://www.instagram.com/fumiya_mainac/)

## 1. コンセプト

> **日常の何気ない疑問や不便を、プロダクトデザインで解決する。**

- シリーズ名（全投稿共通）：**「日常のモヤっとをデザインする」**
- 表紙の定型：`#No.XXX` ＋ 課題の一文（あるある）＋ 小さく商品名
- ゴール：企業タイアップの獲得（詳細は §7）

## 2. チーム（2名体制）

| 担当 | エージェント | 領域 | 確定させるもの |
| --- | --- | --- | --- |
| Strategist | `instagram-growth-strategist` | マーケティング / Instagram / SNS / 企画 / トレンド / バズ構造 | テーマ、ユーザー課題、投稿構成、キャプション、CTA、ハッシュタグ |
| Designer | `sns-product-designer` | Product Design / Industrial Design / CMF / CG / Visualization | 解決方法、商品コンセプト、商品デザイン、CG |

定義ファイル：`.claude/agents/`

## 3. 投稿スケジュール（週3）

| 曜日 | 役割（投稿の型） | 主な狙い | 推奨フォーマット | 推奨時間 |
| --- | --- | --- | --- | --- |
| **月** | **共感あるある × 解決**（週の看板） | 保存・フォロー | カルーセル 8〜10枚（4:5） | 20:00 |
| **水** | **動きで見せる**（使い方・機構） | リーチ・シェア | リール 15〜25秒（9:16） | 12:00 / 21:00 |
| **金** | **参加型**（A/B案・投票・コメント） | コメント・エンゲージメント | カルーセル 6〜8枚 ＋ ストーリーズ投票 | 19:00 |

※ 時間はインサイトの「フォロワーのアクティブ時間」を見て4週ごとに見直す。

## 4. 1投稿あたりの制作フロー

```
① Strategist：テーマ候補3つ（季節性・共感度・タイアップ適性で採点）
        ↓
② 企画会議（2人で議論）
   - Strategist が課題と狙い・KPI・フォーマットを提示
   - Designer が解決案を最低2案提示 → 比較 → 推奨案
   - Strategist が「一目で伝わるか / 欲しいと思うか」で突っ込み
   - 合意点を決める（何を削り、何を見せ場にするか）
        ↓
③ Designer：解決方法 → 商品コンセプト → 商品デザイン（CMF含む）→ CG 指示
        ↓
④ Strategist：投稿構成 → キャプション → CTA → ハッシュタグ
        ↓
⑤ 相互レビュー（チェックリスト §6）→ output/instagram/YYYY-MM-DD/post.md に保存
```

実行はスラッシュコマンド `/instagram-weekly [週の月曜日 YYYY-MM-DD]` で行う
（`.claude/commands/instagram-weekly.md`）。

## 5. 出力ルール

- 保存先：`output/instagram/YYYY-MM-DD/post.md`（YYYY-MM-DD ＝ 投稿日）
- 1ファイルに以下をすべて含める（テンプレート：`docs/instagram/POST_TEMPLATE.md`）
  0. 企画会議ログ
  1. テーマ
  2. ユーザー課題
  3. 解決方法
  4. 商品コンセプト
  5. 商品デザイン（形状・サイズ・機構・CMF）
  6. CG（シーン別の制作指示 ＋ 英語プロンプト）
  7. 投稿構成（スライド/タイムライン）
  8. キャプション
  9. CTA
  10. ハッシュタグ
  11. タイアップ視点・KPI（内部メモ）
  12. 行動設計シート（止まる → 続きを見る → 保存 → 送る → コメント → フォロー）
  13. 8要素スコア（Hook / 3秒理解 / 共感性 / 意外性 / Before/After / 問題発見 / 商品アイデア / 問い）
  14. 企業視点チェック（「この人に商品企画を頼みたい」と思えるか）
- 週の一覧は `output/instagram/README.md` に追記する

## 6. ビジュアル・ブランドルール

| 項目 | ルール |
| --- | --- |
| 背景 | ウォームグレー `#E9E6E1` ベースのスタジオ背景。生活シーンカットは自然光のみ |
| アクセント | シリーズカラー：サインオレンジ `#FF6A2B`（課題マーカー・矢印・番号のみに使用） |
| 文字 | 見出し：太ゴシック（例：Noto Sans JP Black）/ 本文：Noto Sans JP Medium |

| CG | 4:5（1080×1350）/ 9:16（1080×1920）。レンズ 50〜85mm 相当、ソフトボックス＋リムライト |

### 投稿前チェックリスト

判断は「バズりそう」ではなく行動設計で行う（詳細は `.claude/agents/instagram-growth-strategist.md`）。

- [ ] 行動設計シートの6段階すべてに仕掛けが書けている
- [ ] 8要素スコアに 3 以下がない
- [ ] 企業視点チェック7項目がすべて Yes

- [ ] 1枚目だけで「何の不便か」が3秒でわかる
- [ ] 解決の原理が1文で説明できる
- [ ] 使い方が1カット（またはアニメ3秒）で伝わる
- [ ] 想定素材・工法・売価が書かれている（製造リアリティ）
- [ ] 保存したくなる情報スライド（比較・図解・寸法）がある
- [ ] CTA がコメントの「お題」を明示している
- [ ] ハッシュタグは本採用5個以内
- [ ] 実在ブランドのロゴ・意匠を使っていない

## 7. 企業タイアップに向けたロードマップ

| フェーズ | 期間目安 | やること | 指標 |
| --- | --- | --- | --- |
| Phase 1 型を作る | 1〜3ヶ月 | 週3投稿の型を固定、シリーズ番号で蓄積 | 保存率 3%以上 / 投稿 |
| Phase 2 カテゴリを立てる | 4〜6ヶ月 | 反応の良いカテゴリ（雨・家事・デスク等）を特集化。ハイライト整理 | フォロワー 5,000 / プロフィール遷移率 |
| Phase 3 企業に見つけてもらう | 6ヶ月〜 | 実在カテゴリ製品の「勝手に改善提案」シリーズ、メディアキット作成、プロフィールに問い合わせ導線 | 企業からの DM / 問い合わせ件数 |

各投稿の §11 で「想定タイアップ先カテゴリ」を記録し、月末にカテゴリ別の反応を集計する。
