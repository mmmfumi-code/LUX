# 画像生成AI用プロンプト — STEP 3 コンセプト② 自分仕様に育つベッド（C2-01〜C2-10） v1
- 作成: product-designer ／ 2026-09-28 ／ 対応する本文: `product/03-design-v1-c2.md`、3Dレンダー: `product/designs/v1/c2/`
- 使い方: Midjourney / DALL·E / Firefly / Canva などに英語プロンプトを貼る。3Dレンダー（`C2-XX-three-quarter.png`＝アクセサリー付き、`C2-XX-bare.png`＝素の本体）を参照画像（image prompt / style reference）として併用すると、形と寸法のずれが減る
- 共通の前提: シングル W約1000×L約1980mm、天面高 約200〜250mm、厚み約280mm の白いユーロトップマットレスを載せる。三つ折りの折り目2本がうっすら見える。外枠の側面・頭側に細い「共通レール」（溝）が通り、アクセサリーは工具なしでそこに差し込まれている（ネジ・クランプは見せない）
- 共通の撮影スタイル: プロダクト写真、明るいグレーの無地背景、柔らかい影、右斜め上 3/4 ビュー、50mm 相当、自然光
- ビフォー・アフター用: 各案とも、同じ構図で「アクセサリーなし（bare）」も生成すると SNS・EC の比較画像になる（プロンプトの accessory 部分を削る）
