# 体験ストック（Experience Bank）

> **ここがこのワークフローの心臓部です。**
> AI が書いた「それっぽい記事」と、500円払う価値のある記事の差は、ここに書かれた実体験・数値・失敗談の量で決まります。
> note-writer はここに書かれた事実**だけ**を実体験として使います。書かれていない体験は `【要記入】` として残ります。
>
> 書き方: 箇条書きで OK。数値（期間・金額・件数・時間・%）を 1 つ以上入れる。失敗したことほど価値があります。
> 追記したらエントリ末尾に `used_in:` を空欄のまま置いておくと、使った記事の日付が追記されます。

## テンプレート（コピーして使う）

```
### [ピラーID] 見出し（例: P9 ココナラ初受注まで）
- いつ: 20XX年X月〜X月
- 何をした:
- 数値: （例: 出品3件 / 閲覧120 / 問い合わせ4 / 受注1 / 単価5,000円 / 作業6時間）
- うまくいったこと:
- 失敗したこと・やり直したこと:
- 今ならこうする:
- 使える素材: （スクショ・作例・Before/After・見積書など。公開可否も）
- used_in:
```
